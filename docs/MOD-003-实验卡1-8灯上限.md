## 你要做的（约 5 分钟）

1. 打开工程，File → New Scene → **Basic (Built-in)**，存到 `Assets/Scenes/Demos/LightLimitTest.unity`。
2. 放一个 **Sphere** 在原点，材质用默认 `Lit`，Base Color 设白、Smoothness 设 0（避免高光干扰判断）。
3. 放 **12 盏 Point Light**，围球摆成一圈，距离球约 3~4 个单位，颜色统一用白，Range 设 10~15，Intensity 调到球明显发亮。相机拉到能看清整球。
4. **先记录 A 状态**：`Assets/Settings/URP-HighFidelity.asset` → Inspector → Lighting → Additional Lights → **Per Object Limit = 8**，截图。
5. **改成 B 状态**：把 Per Object Limit 从 8 拖到 **1**，看球，截图。
6. **改成 C 状态**：打开 `Assets/Settings/URP-HighFidelity-Renderer.asset` → Rendering → **Rendering Path 切 Forward+**，再截图。**注意此时 Per Object Limit 仍然是 1，别改回去。**
